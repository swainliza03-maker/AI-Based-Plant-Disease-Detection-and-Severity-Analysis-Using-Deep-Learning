# AI-Based Plant Disease Detection and Severity Analysis Using Deep Learning

## Project Overview

This project uses deep learning to detect plant diseases from leaf images and estimate disease severity based on the affected area.

## Features

- Plant leaf image upload
- Disease classification using CNN
- Confidence score
- Affected area estimation
- Severity level: Low, Moderate, Severe
- Streamlit web application

## Technologies

- Python
- TensorFlow
- CNN
- OpenCV
- NumPy
- Streamlit
- Hugging Face
